# Marks

The Haysam mark alone, 329×329 SVG, for avatars, app icons, stickers and small spaces. Never redraw it.

| File | Ink | Use on |
| --- | --- | --- |
| `haysam-mark-ink.svg` | `ink` #58160C | Lavender and white grounds. |
| `haysam-mark-yellow.svg` | `yellow` #FEE252 | The `night` ground. |
| `haysam-mark-white.svg` | `white` | Photos and images. |
| `haysam-mark-black.svg` | black #000000 | One-colour print only. |

Smallest size: 32px on screen. 4000px PNG and JPG exports are in `exports/logos/`.
