# Logos

The official Haysam lockup: the mark plus the caps HAYSAM wordmark. 1416×329 SVG. Never type, redraw or generate it.

| File | Inks | Use on |
| --- | --- | --- |
| `haysam-logo-ink.svg` | `ink` #58160C | Lavender and white grounds. The default. |
| `haysam-logo-yellow-ink.svg` | mark `yellow` #FEE252, wordmark `ink` | Light grounds when the design uses the yellow accent. |
| `haysam-logo-yellow-white.svg` | mark `yellow`, wordmark `white` | The `night` ground #270601. |
| `haysam-logo-white.svg` | `white` | Photos and images. |
| `haysam-logo-black.svg` | black #000000 | One-colour print only. |

52px tall on a 1080px canvas. Clear space: half the mark's height. Smallest: 32px tall on screen, 20mm wide in print. 6000px PNG and JPG exports are in `exports/logos/`.
