# Sticker

A JetBrains Mono label on a small rounded block, tilted −4°.

## When to use

As a signature detail: a short tag under or beside a headline (`AI VIDEO`, `YANGI`). Counts toward the one-or-two signature details per design.

## Markup

```html
<span class="hs-sticker">AI video</span>
<span class="hs-sticker hs-sticker--fire">Yangi</span>
```

- Default: `yellow` with ink text; `hs-sticker--fire`: `fire` with white text. Match the design's single accent.
- 40px JetBrains Mono Bold caps on a 1080px canvas (`sticker-label`), corners `radius-sticker`.

## Do and don't

- Keep the −4° tilt; one or two words.
