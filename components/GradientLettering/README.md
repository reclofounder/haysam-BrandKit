# GradientLettering

Ink-metal gradient lettering (night → ink → metal-light) with a thin top sheen, for one headline on a light canvas.

## When to use

On a lavender or white canvas, for a headline that should feel solid and premium. Counts toward the one-or-two signature details per design. Not on `night`, where it disappears.

## Markup

```html
<h1 class="headline-future hs-metal">AI darslari</h1>
```

`hs-metal` clips the gradient to the text and repeats it per line, so a two-line headline gets the full gradient on each line.

## Do and don't

- Never add bevels, outlines, 3D extrusion or WordArt effects.
- Use it on one headline per design.
